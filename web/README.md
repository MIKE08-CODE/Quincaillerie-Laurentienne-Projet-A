# web — Application web

Interface web bilingue (FR/EN).

**Stack prévue :** React + Vite.

| Dossier | Rôle |
|---|---|
| `src/api/` | Clients HTTP vers l'API |
| `src/assets/` | Images, polices, styles statiques |
| `src/components/` | Composants UI réutilisables |
| `src/features/` | Modules par domaine fonctionnel |
| `src/hooks/` | Hooks React partagés |
| `src/i18n/locales/{fr,en}/` | Traductions |
| `src/layouts/` | Gabarits de page |
| `src/pages/` | Pages |
| `src/routes/` | Définition des routes |
