# desktop — Application de bureau

Application Windows de Quincaillerie Laurentienne.

**Stack prévue :** C# .NET 8, WPF, patron MVVM.

| Dossier | Rôle |
|---|---|
| `src/QuincaillerieLaurentienne.Desktop/Models/` | Modèles de données |
| `src/QuincaillerieLaurentienne.Desktop/ViewModels/` | ViewModels (logique de présentation) |
| `src/QuincaillerieLaurentienne.Desktop/Views/` | Vues XAML |
| `src/QuincaillerieLaurentienne.Desktop/Services/` | Services (accès API, navigation…) |
| `src/QuincaillerieLaurentienne.Desktop/Resources/` | Styles, dictionnaires, traductions |
| `tests/` | Tests |

Les fichiers `.sln` / `.csproj` seront générés plus tard avec `dotnet new`.
