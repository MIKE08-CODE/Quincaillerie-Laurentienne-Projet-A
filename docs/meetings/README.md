# Comptes rendus de réunions (cahier §2 : « Le compte rendu est versé dans `/docs/meetings/` »)

**Aucun compte rendu réel n'est encore déposé.** Un fichier par réunion : `AAAA-MM-JJ-type.md`
(p. ex. `2026-11-24-planification-s2.md`). Ne créer un compte rendu que pour une réunion qui a eu lieu,
avec ses participants réels.

Réunions attendues par le cahier (sprints d'une semaine) : planification le lundi, mêlée quotidienne
de 15 minutes, revue et rétrospective en fin de sprint.

## Gabarit

```markdown

**Date et heure :** AAAA-MM-JJ, hh:mm · **Durée :** … · **Type :** planification / mêlée / revue / rétrospective
```
