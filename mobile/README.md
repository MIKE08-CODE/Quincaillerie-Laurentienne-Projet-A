# mobile — Application mobile

Application mobile bilingue (FR/EN).

**Stack prévue :** React Native + Expo.

| Dossier | Rôle |
|---|---|
| `src/api/` | Clients HTTP vers l'API |
| `src/components/` | Composants UI réutilisables |
| `src/features/` | Modules par domaine fonctionnel |
| `src/navigation/` | Navigateurs et configuration de navigation |
| `src/screens/` | Écrans |
| `src/i18n/locales/{fr,en}/` | Traductions |
| `assets/` | Icônes, splash, images |
